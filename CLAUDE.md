# StarFall: rules for every session in this repository

## Permission (Michael's standing rule)

Feedback is not permission. A description of a problem is not a request to fix it. Never run, build, write, spend or change anything without Michael's explicit go.

This covers code, design files, the spoiler folder, test runs, agent runs, image requests (each one costs money on Michael's OpenAI account), commits and pushes. When Michael points out a problem, describe what you would do and wait for his go.

The scheduled game turns (the 1:30am save and world turn, the 6:30am morning story) run under the design Michael approved; they are the exception, and only for the work the design assigns them.

The same exception covers a campaign once its player has started it, and a test run once Michael has started it: the whole of it, its creation days and nights (`engine/night/creation-nights.md`) and its play days and nights, runs under the approved design. An agent working inside such a run (the DM, the Keeper, an NPC god, a civ agent, the checker) takes its release or role file as Michael's go for exactly the files that release or role file names, including the commits and pushes the design assigns, and for nothing else. A `git pull --rebase --autostash` is always allowed inside a run; it writes no file of the agent's own. No step inside a run waits on Michael: a ruling the files do not settle is made by the Keeper (or the checker, at the lock) by the judgment order in `engine/roles/keeper.md`, applied, and logged for review, and the run goes on; image approvals come from the campaign's `state/images.md`. In a test run the same holds, except for a ruling Michael has asked to make himself. Rulings Michael gives in chat during a run are recorded in the campaign's sealed `SPOILERS_do_not_open/campaigns/<name>/rulings.md`, written only by the orchestrator from his words, quoted, with the Pacific time and the question he answered; each entry carries Michael's go for exactly what it says, and no agent writes or edits it. Nothing in a run authorizes a change to the engine, the design, or the Keeper's standing files, or spending beyond `state/images.md`; those still need Michael's explicit go. The continuity checker reviews everything a run writes.

## Writing

Never use em dashes or en dashes. Use periods and commas; hyphens only in compound adjectives.
