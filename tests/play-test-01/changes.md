|---|---|---|---|---|
| 1 | Setup, S6 | Setup asks the player to name the campaign before anything else about the game. Michael, 21:23: "it is asking me to name the campaign as the first thing. That is stupid. It should be the last thing... I have no sense of what the game is yet. In fact... maybe the game should always be called starfall... I'm not sure. but naming it as the first thing is dumb". | Setup never asks for a name. The campaign folder is always `starfall` (`tools/new_campaign.py` defaults to it), so each player's copy holds one campaign called `starfall`. The GitHub copy's name (S3) stays, since GitHub needs it, with `StarFall-<their name>` suggested. Michael, 21:24: "yeah, StarFall-<new name> works". | on the list (Michael, 21:26: "just add it to the change list") |
