# Creation simulation

A repeatable test of the three creation days and nights. A stand-in player agent plays Days 1 to 3 against the DM agent; the Keeper runs Nights 1 to 3 for real, under the creation runbook, in one sitting. Each run is a fresh campaign: run 01 is `campaigns/sim-01`, run 02 is `campaigns/sim-02`, and so on.

Per run, this folder holds:
- `stand-in.md`: the stand-in player's brief.
- `transcript-day2.md`, `transcript-day3.md`: the table talk, as relayed.
- `timing.md`: when each stage started and finished, and which models ran.
- `changes.md`: the change list. Proposals only. Nothing in the engine changes until Michael approves a line.

Agents report process problems (unclear instructions, missing paths, contradictions) without spoilers, so the change list can be read by the player.
